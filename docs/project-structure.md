# Структура файлов проекта Квайз

## Папки и назначения
- `/tokens`: Централизованное хранение токенов стилей (colors, typography, spacing, radius, breakpoints, index).
- `/src/components`: Атомы, молекулы, блоки и специфичные элементы UI.
- `/src/pages`: Страницы сборки интерфейса.
- `/src/server`: Backend сервера Express + SQLite базы данных.
- `/docs`: Документация арт-дирекшна и структуры проекта.

## Правила компонентизации
1. Компонент запрашивает стили через глобальные переменные токенов (`var(--color-primary)` и т.д.).
2. Каждая страница собирает функциональные блоки и не переопределяет глобальные системные правила.
3. Интерактивная панель твиков дизайна (`DesignTweaker`) позволяет на лету менять параметры токенов и копировать готовый CSS код.
